## At a glance

**Purpose:** help maintainers, stewards, manufacturers, and communities use
practical cybersecurity-policy guidance, without confusing recommendations with
legal duties.

**Example pilot:** five logical slices, reusing three existing issues and one
existing PR, plus one conditional new crosswalk proposal. There is no need to
create five new issues.

**Participation:** improve wording, review interpretations, try an example,
translate, bring regional experience, or help deliver a community activity.
Comment on the linked upstream record if contributing to that existing work;
preview-only proposals below do not yet have public discussion threads.

## Forums and standing programs

- **Main WG:** policy, standards updates, consultations, and coordination.
- **GCP Awareness SIG:** guidance, learning, publications, and outreach.
- **CRA Office Hours:** community questions and recurring guidance gaps.
- **APAC SIG:** regional participation and feedback, including possible input to
  the scenarios work. This is an invitation, not an assignment.

Standing programs are not permanent unfinished issues. Their agreed finite
outputs can be tracked alongside the five pilot slices.

## What changes when this becomes live

The repository's overview will link to real Project views for **Roadmap**,
**By group**, **Delivery**, **Proposals**, **Help wanted**, and **Delivered**.
Existing issues keep their URLs, discussion, and assignees. Approved new work
gets a real issue only after checking for overlap. This example and any mockup
are review snapshots, not a second manually maintained source of live status;
replace them with Project links at launch.
